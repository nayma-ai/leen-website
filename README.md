# leen.fit

Marketing site for **Leen | لين** — the food journal for iPhone. English at `/`,
Arabic (RTL) at `/ar/`, plus privacy and terms pages in both languages.

Plain HTML/CSS/JS generated by a zero-dependency Node script. No framework,
no trackers, no third-party requests (fonts are self-hosted).

## Run it

```bash
npm run dev      # http://localhost:4173 — rebuilds on every save
npm run build    # writes the deployable site to site/
```

Node 20+ is the only requirement.

## Where things live

| Path | What |
|---|---|
| `src/content.mjs` | **All copy**, English and Arabic side by side, plus `site` settings (App Store link, contact email). Demo nutrition numbers come from the app's `NutritionDB.swift`. |
| `src/legal.mjs` | Privacy policy and terms, both languages. |
| `src/pages.mjs` | Page templates — every section of the homepage, legal pages, 404. |
| `src/components.mjs` | Shared pieces: food tiles, meal cards, the iPhone frame, icons. |
| `static/assets/css/site.css` | Design system. Colors mirror `Shared/JournalTheme.swift`; food tiles mirror `ProceduralFoodArt.swift`. |
| `static/assets/js/site.js` | Hero demo, correction demo, gentle mode, theme picker, mobile menu, reveals. |
| `scripts/og.mjs` | Regenerates the social preview images (`static/og-en.png`, `og-ar.png`) with headless Chrome. |

Because both languages render from one template, a section can't exist in
one language and not the other. To change wording, edit `src/content.mjs`.

## On launch day

Set `appStoreUrl` in `src/content.mjs`. Every "Coming soon" button becomes a
real "Download on the App Store" link. (Set `testflightUrl` instead to show a
"Join the beta" button before launch.)

## Deploying (GitHub Pages)

1. Push this folder to a GitHub repo; `.github/workflows/deploy.yml` builds
   and publishes `site/` on every push to `main`.
2. Repo → Settings → Pages → Source: **GitHub Actions**. Custom domain:
   `leen.fit`, then tick **Enforce HTTPS** once the certificate is issued.
3. At the domain registrar, point DNS at GitHub Pages:

   | Type | Name | Value |
   |---|---|---|
   | A | `@` | `185.199.108.153` |
   | A | `@` | `185.199.109.153` |
   | A | `@` | `185.199.110.153` |
   | A | `@` | `185.199.111.153` |
   | AAAA | `@` | `2606:50c0:8000::153` |
   | AAAA | `@` | `2606:50c0:8001::153` |
   | AAAA | `@` | `2606:50c0:8002::153` |
   | AAAA | `@` | `2606:50c0:8003::153` |
   | CNAME | `www` | `<github-user-or-org>.github.io` |

   Verify the domain in GitHub account/org settings → Pages to stop anyone
   else claiming it.

Any static host works too (Cloudflare Pages, Netlify, Vercel): build command
`node build.mjs`, output directory `site`.
